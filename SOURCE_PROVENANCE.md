# Source provenance and upstream status

## Verified original mod publisher

The mod **Mielon's The Sift** is published under the name **Mielon** at the following author-facing pages:

- [Modrinth — Mielon's The Sift](https://modrinth.com/mod/mielons-the-sift)
- [CurseForge — Mielon's The Sift](https://www.curseforge.com/minecraft/mc-mods/mielons-the-sift)

Those listings state the project's MIT license. This port retains the source's © 2026 Mielon MIT copyright and its original asset/creative contributor credits.

## Public code source used for the port

The local Git history used to build this port originates in the public repository [Arta48/Mielons-The-Sift](https://github.com/Arta48/Mielons-The-Sift). **Arta48 is the GitHub repository owner, and we have not established that Arta48 is Mielon or an authorized maintainer.** The GitHub repository's MIT license names Mielon as its copyright holder, but a copyright notice alone does not verify that the repository is officially maintained by that person.

Accordingly, this project is a community port based on the **public source repository hosted by Arta48**, with explicit credit to Mielon as the creator of the mod and to Arta48 as the publisher of the code snapshot used. Do not describe the Arta48 repository as Mielon's official or original GitHub repository without direct confirmation from Mielon.

The local port's lineage is recorded in Git, while new adaptation and repair commits are attributed separately to MikiKox1. Our port does not imply that Mielon has reviewed or approved the adaptations.

## Publishing guidance

The safest description is **"Unofficial AI-assisted NeoForge port of Mielon's The Sift, based on the publicly available Arta48 source snapshot"**. Publishing it as an independent repository makes the distinction clearer than presenting a GitHub fork of Arta48 as an official fork of Mielon's own repository. If Mielon provides a verified official upstream GitHub repository later, update the source links and review code provenance before changing the relationship claim.
