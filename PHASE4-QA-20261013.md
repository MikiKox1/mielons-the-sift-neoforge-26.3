**Original debugging chronology retained, not mislabeled:** Initial 26.2 compilation failed due to RenderPearl/Blaze3D API migration. First dedicated server failed on FML 12 vs 11, then on missing carver-replaceable tag; both corrected. The first client boot failed on 26.3 \`rainTexture\` \`@Shadow\`; another attempt failed on overloaded weather method descriptor; the next failure came from a stale RenderPearl-type descriptor in the air HUD mixin. Those were fixed against actual Minecraft26.2 bytecode and the **later** isolated client reached the menu. Historical crash reports live only in the disposable test profile; they are not evidence that the last build crashes.

**Data-map corrections:** Removed unsupported NeoForge26.3 \`neoforge:transformables\`, added NeoForge26.2 \`strippables\` mapping for the two willow variants; populated \`sift_carver_replaceables\` from pinned Fabric26.2 reference; registered natural \`minecraft:sniffer\` placement with ground/mob restrictions to eliminate a previous server warning. All later tested server logs have 0 ERROR/FATAL.

**Render shader warnings:** Native/OpenGL shader compilation logs included some unused \`Sampler0\`/\`Sampler1\` uniforms for \`the_sift:pipeline/sift_portal\` and the non-Rift variant of \`pipeline/portal_loading\`. The shaders are procedurally generated; their unused samplers appear in the original pipeline and are optimized out in some branches. These warnings were nonfatal during menu startup. **In-world visual parity is still PENDING**; do not delete portal layers, textures or shader functionality just to suppress warnings.

**Optional library references:** The exact official Easy Magic/Puzzles Lib JARs were pinned by SHA-512 from Modrinth and copied **only** to the disposable Prime2 client/server \`mods\` folders. Manifest: \`TheSift/backports/26.2-1.1.2-prep/reference/optional-easymagic-262/OFFICIAL-MODRINTH-SOURCE-PINS-20261013.json\`. The standalone The Sift JAR does **not** bundle those mods or depend on them for startup. \`tools/tests/verify_optional_easymagic262.py\` verifies the separate logs and hashes.

**Runtime scope:** The dedicated server was stopped via console interrupt after smoke, not a proven graceful gameplay shutdown. A saved disposable world was reloaded at bootstrap; no player logged into the world or executed game commands. The client was closed after confirming its responsive window and resource initialization. Both tests occurred entirely within \`TheSift/work/neo-26.2-upstream-1.1.2/run/\`. No user character, personal saves, modpack or live profile was modified.
